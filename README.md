# Contact Manager

A simple contact manager project in Python.

This project runs in the terminal. You can save, view, edit, favorite, and delete your contacts.

## Features

- **Add contact:** Save a new contact with name, phone, and email.
- **View contacts:** See your list of contacts and favorite status.
- **Edit contact:** Change the name, phone, or email of an existing contact.
- **Favorite contacts:** Mark or unmark contacts as favorites.
- **Filter favorites:** View only your favorite contacts.
- **Remove contact:** Delete a contact from the list.
